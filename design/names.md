# Names

The default here is a two-word mash of Focus, Pomo or Tomato with Flow, Buddy or Mate. Avoided.
"Pomodoro" itself is a registered trademark of Francesco Cirillo, which is one more reason to keep
it out of the name.

Checked 2026-11-24: GitHub repository search by name, and a Play Store app search. A small repo with
the same name is a nuisance, an app with the same name in the same store is a blocker.

| Name | Why | Clashes found |
|---|---|---|
| **heirloom** (recommended, with route B) | An heirloom tomato, and the thing you hand down: your past records are the heirloom past you leaves to present you. | GitHub: abronan/heirloom, a 9-star CLI Pomodoro tool, same category, inactive; Heirloom Project (Unix tools). Play: only "Hidden Legacy: Heirloom" games. Usable; check the trademark register. |
| **truss** | A truss is the cluster of tomatoes ripening on one stem: a small study group. | GitHub: basetenlabs/truss (1.2k stars, ML serving). Play: "Truss: Moving & Delivery", truss calculators. Crowded. |
| **fourstroke** | Four strokes of a tally, a set of four, and an engine that keeps turning over. | GitHub: three empty repos. Play: engine-simulator apps only. Clear, but reads as motoring. |
| **fivebar** | The five-bar gate is the real name of the tally group. | Play: "fivebar: Tally Counter" exists. Blocked. |
| **tomatl** | The Nahuatl word that "tomato" comes from: the cliché, turned back to its root. | GitHub: tomatl-dev (tax code), small repos. Play: nothing by that name. Clear, but people will not know how to say it. |
| **sitting** | "In one sitting": a session, and sitting down to work beside a friend. | Play: several "Sitting reminder" apps. Generic, hard to search for. |
| **ghostpace** | Racing your own past pace. | GitHub: "Race a ghost pace through your exam papers" (1 star, same idea for exams). Play: none. Clear on Play, but a near twin exists. |
| **contaminuti** | Italian for kitchen timer, the thing Cirillo actually wound. | None found. Too long to type and to say. |
| **calyx** | The green star on top of a tomato, route C's one drawing. | GitHub: calyxir (618 stars), a terminal app; Play: Calyx gym, cycle tracker, PGP apps. Blocked. |
| **deskmate** | The friend at the next desk. | Play: "Deskmate" and "Deskmates" exist. Blocked. |

Recommendation: **heirloom**. It carries route B's idea (your own past is the thing you keep), it is
a real tomato word without saying tomato, and the only clash in the category is a dormant CLI repo.
